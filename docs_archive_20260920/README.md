# 指标体系历史归档

此目录保留合并远端更新前的指标资料，供复现与审计。当前有效源文件位于同级前台仓库 `fore-end/docs/农业及相关产业动态指标搜集体系.{xlsx,md}`：3023 条、15 列，包含适用范围和区域标签。

| 文件 | 内容 |
| --- | --- |
| `农业及相关产业动态指标搜集体系.{xlsx,md}` | 原始东北版本，3020 条、14 列 |
| `农业及相关产业动态指标搜集体系_全国化14列历史版.{xlsx,md}` | 本地全国化中间版本，3020 条、14 列；统一区域文字，保留地域特色语义 |

全国化过程报告保留在 `data/nationalize_report.csv`（扫描）、`data/nationalize_changes.csv`（逐格变更）及 `data/nationalize_verify.csv`（核验）。这些是历史快照，不代表新版 15 列源文件或当前运行数据库的状态。

本次同步保留远端新增的「全国通用 / 区域可配置 / 示例：东北」三类适用范围、区域标签及 3 条区域示例，未使用中间版本覆盖新版源文件。旧版将区域统一为「全国」的做法只用于解释历史改造，不适用于当前配置流程。
